## Сервер - где смотреть

**Адрес админки:** `http://localhost:8080/admin`

Но прежде нужно запустить сам сервер - сейчас у тебя Docker (Colima) не запущен. Сделай так:

1. Открой Terminal
2. `colima start` (запустит Docker daemon)
3. `cd "Projects/transcribe-app/server" && docker-compose up -d`
4. Подожди 30 сек пока поднимется
5. Открой http://localhost:8080/admin

После этого записанные встречи будут попадать туда автоматически (если галочка «Отправить в облако Insapp» оставлена ✓ при записи).

Если сервер не поднимется - я могу залезть и починить, но нужно решение про Colima/Docker первого запуска.
